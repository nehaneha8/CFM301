# Project 2: Market-Leverage Factor (LEV)

Tests whether high-minus-low market leverage, `debt / (debt + market equity)`, is a priced factor beyond market, size, value and momentum (CRSP + Compustat, Jan 1974 - Dec 2018).

## How to run
1. `pip install pandas numpy jupyter`
2. Open `proj2.ipynb` and **Run All** (about 2 minutes, needs ~4 GB RAM and an internet connection).

The notebook reads the two compressed raw files in this folder (`pandas` reads `.csv.gz` directly), regenerates `stock_timed.csv` and `permnos.txt`, and downloads the Fama-French and momentum factors from Ken French's data library.

## Files
| File | What it is |
|---|---|
| `proj2.ipynb` | Full analysis: data cleaning, factor, regressions, sensitivity, bad times, results |
| `compustat.csv.gz` | Raw WRDS Compustat quarterly fundamentals + CCM links |
| `crsp_monthly.csv.gz` | Raw WRDS CRSP monthly stock file |
| `permnos.txt` | PERMNO list used for the CRSP query (regenerated by the notebook) |
| `stock_timed.csv` | Generated by the notebook (not committed, about 220 MB) |

Results are summarised in section 9 of the notebook.
