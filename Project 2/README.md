# Project 2: Market-Leverage Factor (LEV)

Tests whether high-minus-low market leverage, `debt / (debt + market equity)`, is a priced factor beyond market, size, value and momentum (CRSP + Compustat, Jan 1974 - Dec 2018).

## How to run
1. `pip install pandas numpy matplotlib jupyter`
2. Open **`Project2_Combined_Submission.ipynb`** (the submission notebook) and **Run All** (about 2-3 minutes, ~4 GB RAM, no internet needed).

The notebook reads the two compressed raw files in this folder (`pandas` reads `.csv.gz` directly) and the Fama-French file `04_Fama_French_Monthly_Factors.csv`, and regenerates `stock_timed.csv` and `permnos.txt`.

## Files
| File | What it is |
|---|---|
| `Project2_Combined_Submission.ipynb` | **Submission notebook:** rationale, cleaning, factor, regressions, independent test assets, sensitivity, bad times, charts, results, rational vs behavioral, efficiency, checklist |
| `proj2.ipynb`, `01_Corporate_Leverage_Factor_Study.ipynb` | Earlier individual notebooks (superseded by the combined notebook) |
| `04_Fama_French_Monthly_Factors.csv` | Monthly Mkt-RF, SMB, HML, momentum, RF (decimals) |
| `compustat.csv.gz` | Raw WRDS Compustat quarterly fundamentals + CCM links |
| `crsp_monthly.csv.gz` | Raw WRDS CRSP monthly stock file |
| `permnos.txt` | PERMNO list used for the CRSP query (regenerated by the notebook) |
| `fig1_*.png`, `fig2_*.png` | Charts produced by the notebook |
| `stock_timed.csv` | Generated by the notebook (not committed, about 220 MB) |

Results are summarised in section 9 of the combined notebook. Charts are saved as `fig1_lev_vs_hml.png` and `fig2_bad_times_quintiles.png`.
